# BAR RECIPE

홈바 칵테일 재료, 레시피, 주문을 한 기기에서 관리하는 반응형 웹앱입니다.

## 실행

`index.html`을 최신 브라우저에서 열면 바로 사용할 수 있습니다. 로컬 서버를 쓰고 싶다면 이 폴더에서 다음 명령을 실행한 뒤 안내된 주소를 여세요.

```bash
python -m http.server 8000
```

## 화면

- 손님 화면: 주문 가능한 메뉴를 보고 주문합니다. 상단 `관리자 모드`를 누르면 운영 화면으로 이동합니다.
- 운영 화면: 재료 보유 상태, 레시피 메뉴 공개 여부, 대기 주문을 관리합니다. `메뉴판으로 돌아가기`로 손님 화면에 복귀합니다.
- 레시피를 등록할 때 재료 이름은 재료 목록의 이름과 일치해야 보유 중으로 판단합니다.
- `JSON 가져오기`에서 레시피 JSON 파일을 선택하면 내용을 확인한 뒤 기존 목록에 병합합니다. 이름이 겹치는 레시피·재료는 건너뛰고, 가져온 레시피는 메뉴에 자동 공개되지 않습니다.
- `JSON 내보내기`는 재료 보유 상태와 전체 레시피를 JSON 파일로 내려받습니다. 내보낸 파일은 다시 가져올 수 있습니다.

가져오기는 `{ "recipes": [...] }` 형식 또는 레시피 객체 배열을 지원합니다. 각 레시피에는 `name`, `abv`, `glass`, `ingredients`(재료 객체의 `name`, 선택 `qty`), `method`가 필요합니다. 선택 항목은 `english`, `note`입니다. 내보낸 JSON은 재료 배열도 포함합니다.

## 저장 및 초기화

데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 같은 기기와 브라우저에서 다시 열면 데이터가 유지됩니다. 브라우저 개발자 도구의 콘솔에서 아래 코드를 실행하면 초기 예시 데이터로 되돌아갑니다.

```js
localStorage.removeItem('bar-recipe-v1');
location.reload();
```

이 MVP는 단일 기기용이며 계정과 서버 동기화는 포함하지 않습니다.
